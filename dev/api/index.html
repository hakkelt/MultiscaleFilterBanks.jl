API Reference

MultiscaleFilterBanks exports nothing; every name below is public. Load the ones you need explicitly, e.g. using MultiscaleFilterBanks: CDF97, upsample_filter.

MultiscaleFilterBanks.MultiscaleFilterBanks — Module
MultiscaleFilterBanks

Shared core of the multiscale, multidirectional filter-bank transforms Contourlets.jl (2-D contourlets), Surfacelets.jl (3-D surfacelets) and Shearlets.jl (2-D and 3-D shearlets): everything that is neither 2-D nor 3-D specific.

The package exports nothing; its API is declared public. Load names explicitly, e.g. using MultiscaleFilterBanks: CDF97, upsample_filter. The downstream packages re-export the filter names, so their users do not need to.

  • Filters: FilterPair, CDF97, upsample_filter.
  • Nonsubsampled pyramid: nsp_atrous_filters, nsp_responses, centred_dtft.
  • Mask-bank engine: MaskBankEngine, MaskItem, mask_bank_forward!, mask_bank_inverse!, mask_bank_subband, mask_bank_coarse.
  • Threading: use_threading, loop_threaded, foreach_chunk, chunked_sum!, add_partials!, n_tasks, with_fftw_threads.
  • Element types and boundaries: data_eltype, filter_eltype, clamp_idx.

Filters

MultiscaleFilterBanks.FilterPair — Type
FilterPair{T}

A 1-D biorthogonal filter pair holding an analysis (h) and synthesis (g) low-pass filter vector. Both filters are stored as coefficient vectors whose centre tap is at index ceil(Int, length/2) (1-based Julia indexing).

The pair drives the pyramid stage of the downstream transforms: h produces the coarse approximation, and g predicts the input from it, so that the difference is a bandpass (the Laplacian pyramid of Burt and Adelson [1]). Adding the prediction back reconstructs the input for any pair. Do and Vetterli [2] show that the pyramid is a frame, tight for orthogonal filters, and give a projection reconstruction that is more robust to noise than the usual one. Its nonsubsampled (à trous) form is the pyramid of the nonsubsampled contourlet transform [3].

Examples

julia> using MultiscaleFilterBanks: FilterPair

julia> fp = FilterPair([0.5, 1.0, 0.5], [0.25, 0.5, 0.25]);

julia> eltype(fp)
Float64

  1. P. J. Burt and E. H. Adelson, "The Laplacian Pyramid as a Compact Image Code", IEEE Transactions on Communications, 31(4):532–540, 1983. doi:10.1109/TCOM.1983.1095851
  2. M. N. Do and M. Vetterli, "Framing Pyramids", IEEE Transactions on Signal Processing, 51(9):2329–2342, 2003. doi:10.1109/TSP.2003.815389

MultiscaleFilterBanks.CDF97 — Constant
CDF97 :: FilterPair{Float64}

The Cohen–Daubechies–Feauveau 9/7 biorthogonal filter pair [1], the irreversible wavelet filter of JPEG 2000 Part 1 [3], introduced for image coding by Antonini et al. [2]. The 9-tap analysis low-pass h is normalised to unit DC gain, the 7-tap synthesis low-pass g to DC gain 2, which compensates the ×2 upsampling of the Laplacian pyramid's synthesis step. Both are symmetric, centred at taps 5 and 4.

julia> using MultiscaleFilterBanks: CDF97

julia> isapprox(sum(CDF97.h), 1.0; atol = 1e-12)
true

julia> isapprox(sum(CDF97.g), 2.0; atol = 1e-12)
true

References

  1. A. Cohen, I. Daubechies, and J.-C. Feauveau, "Biorthogonal Bases of Compactly Supported Wavelets", Communications on Pure and Applied Mathematics, 45(5):485–560, 1992. doi:10.1002/cpa.3160450502
  2. M. Antonini, M. Barlaud, P. Mathieu, and I. Daubechies, "Image Coding Using Wavelet Transform", IEEE Transactions on Image Processing, 1(2):205–220, 1992. doi:10.1109/83.136597
  3. ISO/IEC 15444-1, Information technology — JPEG 2000 image coding system: Core coding system.

MultiscaleFilterBanks.upsample_filter — Function
upsample_filter(h::AbstractVector, factor::Int) -> Vector

Insert factor - 1 zeros between every tap of h. If h has frequency response $H(ω)$, the result has response $H(\text{factor}\,ω)$.

This is the filter upsampling of the algorithme à trous ("with holes") [1]: level $j$ of an undecimated pyramid filters with the level-1 filters upsampled by $2^{j-1}$ instead of decimating the signal, which computes the undecimated (shift-invariant) wavelet transform [2]. The nonsubsampled pyramid and the nonsubsampled directional filter banks of the downstream packages use it in the same way [3].

Examples

julia> using MultiscaleFilterBanks: upsample_filter

julia> upsample_filter([1.0, 2.0, 3.0], 2)
5-element Vector{Float64}:
 1.0
 0.0
 2.0
 0.0
 3.0

References

  1. M. Holschneider, R. Kronland-Martinet, J. Morlet, and Ph. Tchamitchian, "A Real-Time Algorithm for Signal Analysis with the Help of the Wavelet Transform", in Wavelets: Time-Frequency Methods and Phase Space, Springer, 1989, pp. 286–297. doi:10.1007/978-3-642-75988-8_28
  2. M. J. Shensa, "The Discrete Wavelet Transform: Wedding the À Trous and Mallat Algorithms", IEEE Transactions on Signal Processing, 40(10):2464–2482, 1992. doi:10.1109/78.157290

Nonsubsampled pyramid

MultiscaleFilterBanks.nsp_atrous_filters — Function
nsp_atrous_filters(fp::FilterPair, level, Tf) -> (h, g)

The à trous analysis and synthesis filters of nonsubsampled-pyramid level level in precision Tf: fp.h and fp.g upsampled by 2^(level - 1) (upsample_filter), with the synthesis filter halved to unit DC gain. The pyramid does not decimate, so the gain of 2 that compensates the ×2 upsampling of the decimated Laplacian pyramid must go. Apply the pair along every axis.

source
MultiscaleFilterBanks.nsp_responses — Function
nsp_responses(fp::FilterPair, J, n; bins = 1:n) -> (a, gh, s)

The J-level nonsubsampled pyramid on one n-point DFT axis, as frequency responses at the bins bins (ComplexF64 vectors). With Hⱼ, Gⱼ the responses of the level-j à trous pair,

a[j] = Π_{i<j} Hᵢ  (j ≤ J + 1),   gh[j] = Gⱼ Hⱼ  (j ≤ J),   s[j] = Π_{i<j} Gᵢ  (j ≤ J + 1).

Periodic separable filtering is a pointwise product on the DFT grid, so on a D-dimensional grid the bandpass of level j is Π_d a_d[j] · (1 − Π_d gh_d[j]), the lowpass Π_d a_d[J + 1], and their synthesis masks Π_d s_d[j]; with them Σⱼ synthesis · analysis = 1 telescopes. Each mask is a broadcast of per-axis vectors, never stored at full size.

source
MultiscaleFilterBanks.centred_dtft — Function
centred_dtft(f, θ) -> Complex

The discrete-time Fourier transform at θ of the filter f with its centre tap at (length(f) + 1) ÷ 2: the frequency response of the centred convolution the pyramids apply.

Mask-bank engine

The engine behind the nonsubsampled transforms of the downstream packages: a nonsubsampled pyramid followed by nonsubsampled directional banks, run as pointwise products on the DFT grid in any dimension.

MultiscaleFilterBanks.MaskBankEngine — Type
MaskBankEngine(pyramid_ana, pyramid_syn, coarse_ana, coarse_syn, banks, items, X, pfwd, pinv)

The precomputed masks, FFT plans and buffers of a nonsubsampled pyramid followed by nonsubsampled directional banks, all on one DFT grid (the rfft half-space for real data), in any dimension.

  • pyramid_ana[g], pyramid_syn[g]: the analysis and synthesis masks of pyramid bandpass g; coarse_ana, coarse_syn those of the lowpass.
  • banks: directional banks, anything with ana and syn vectors of channel masks.
  • items: every output as a MaskItem, with the items of one pyramid mask consecutive.
  • X: the spectrum buffer; pfwd / pinv: single-threaded plans from data to spectrum and back.

With X̂ the input spectrum, output (g, b, k) is ifft(banks[b].ana[k] · pyramid_ana[g] · X̂) and the lowpass is ifft(coarse_ana · X̂); the synthesis sums the outputs back with the syn masks. mask_bank_forward! and mask_bank_inverse! run the engine. The constructor allocates one FFT buffer per task (n_tasks).

source

MaskItem(index::NTuple{N, Int}, pyramid::Int, bank::Int, channel::Int)

One output of a MaskBankEngine: where it sits in the coefficient container (index, passed to mask_bank_subband), the pyramid mask that feeds it, and the bank and channel that split that mask.

MultiscaleFilterBanks.mask_bank_forward! — Function
mask_bank_forward!(coeffs, x, e::MaskBankEngine, threaded::Bool) -> coeffs

Analysis of the dense input x into the subbands and lowpass of coeffs. With threaded, the outputs are split between tasks (foreach_chunk) unless an enclosing NestedThreading budget forbids it (loop_threaded). Allocates nothing.

source
MultiscaleFilterBanks.mask_bank_inverse! — Function
mask_bank_inverse!(x, coeffs, e::MaskBankEngine, threaded::Bool) -> x

Synthesis of the subbands and lowpass of coeffs into the dense output x, the inverse of mask_bank_forward! for masks that sum to one. Threaded like the analysis, with one partial sum per task (chunked_sum!). Allocates nothing.

Threading

MultiscaleFilterBanks.use_threading — Function
use_threading(threaded::Union{Bool, Nothing}, T::Type) -> Bool

Resolve a transform's threaded keyword for data of element type T: true and false are taken as given; nothing (let the transform decide) threads complex data only, since a vectorised serial loop wins for real data in the direct-convolution transforms. Transforms whose work is dominated by FFTs may resolve nothing to true instead.

julia> using MultiscaleFilterBanks: use_threading

julia> use_threading(nothing, Float64), use_threading(nothing, ComplexF64), use_threading(true, Float64)
(false, true, true)
source
MultiscaleFilterBanks.loop_threaded — Function
loop_threaded(threaded::Bool) -> Bool

Whether a call that asked to thread may: threaded, and no enclosing NestedThreading.jl restriction (a caller's @budgeted_threads loop or with_restricted_threads scope) has lowered this package's thread budget to one. Read it once per transform call and pass the answer to every loop of the call.

source
MultiscaleFilterBanks.foreach_chunk — Function
foreach_chunk(f, n::Int, nt::Int, threaded::Bool)

The threaded loop over independent work items, such as the FFTs of a filter bank's subbands. Calls f(range, t) for each of nt contiguous, balanced chunks of 1:n in parallel when threaded, otherwise f(1:n, 1) once. Index per-task buffers by the chunk number t, never by thread id: they then need no locks and the tasks may migrate. An exception thrown by f is rethrown after all chunks finish. Call it with threaded = loop_threaded(...) (see loop_threaded).

source
MultiscaleFilterBanks.chunked_sum! — Function
chunked_sum!(f, acc, partials, n::Int, threaded::Bool) -> acc

A sum over 1:n split like foreach_chunk into length(partials) + 1 tasks: f(a, range, t) adds the terms of its chunk into a, which is acc for the first task and the zeroed partials[t - 1] for the others. The partials are then added into acc (add_partials!).

source
MultiscaleFilterBanks.add_partials! — Function
add_partials!(acc, partials, threaded::Bool) -> acc

acc .+= sum(partials). For host arrays each task takes a contiguous slice of acc and adds every partial into it one cache-sized block at a time, so acc is read and written once.

source
MultiscaleFilterBanks.n_tasks — Function
n_tasks(X::AbstractArray, n::Int) -> Int

The number of tasks a loop over n independent FFTs on arrays like X splits into: one per Julia thread for an Array, one for any other array type (a device array, whose FFTs are already parallel), and never more than n. Allocate one set of per-task buffers for each.

source
MultiscaleFilterBanks.with_fftw_threads — Function
with_fftw_threads(f, n::Integer)

Run f(), which makes FFTW plans, with FFTW on n threads, and return its result; a plan keeps the thread count it was made with. Unlike FFTW.set_num_threads, it restores the caller's count afterwards and lets an enclosing NestedThreading.jl restriction win, so plans made inside a caller's threaded loop do not oversubscribe it. Without FFTW loaded it just runs f().

Element types and boundaries

MultiscaleFilterBanks.data_eltype — Function
data_eltype(x::AbstractArray)
data_eltype(T::Type{<:Number})

The element type a transform computes in for data x (or of element type T): float(T), so complex stays complex and integers become Float64.

Filters are always real; transforms take Td = data_eltype(x) for the data and Tf = filter_eltype(Td) for the filters, so complex data is filtered by real kernels (complex × real, never complex × complex). That keeps every transform exactly real-linear.

source
MultiscaleFilterBanks.filter_eltype — Function
filter_eltype(Td::Type{<:Number})

The real filter precision for data of element type Td: real(float(Td)) (ComplexF32 → Float32). See data_eltype.

source
MultiscaleFilterBanks.clamp_idx — Function
clamp_idx(i, n, Val(mode)) -> Int

Fold the index i into 1:n for the boundary extension mode of a signal of length n:

  • :symmetric: whole-sample symmetric, the edge sample is not repeated (x[2], x[1], x[2], x[3], …);
  • :periodic: mod1(i, n);
  • :zero: i unchanged; the caller treats indices outside 1:n as zeros.

The mode is a Val so each caller is specialised, with no per-sample dispatch.

julia> using MultiscaleFilterBanks: clamp_idx

julia> [clamp_idx(i, 4, Val(:symmetric)) for i in -1:6]
8-element Vector{Int64}:
 3
 2
 1
 2
 3
 4
 3
 2
