MultiscaleFilterBanks — Module
MultiscaleFilterBanks

Shared building blocks for multiscale, multidirectional filter-bank transforms.

This package holds the pieces that are neither 2-D nor 3-D specific and are used by Contourlets.jl (the 2-D contourlet / nonsubsampled contourlet transform), Surfacelets.jl (the 3-D nonsubsampled and decimated surfacelet transforms) and Shearlets.jl (2-D and 3-D shearlets):

ExportDescription
FilterPair1-D biorthogonal analysis/synthesis low-pass filter pair
CDF97The CDF 9/7 filter pair used by the pyramid stages
upsample_filterÀ trous ("with holes") filter upsampling
ThreadingPolicy, Auto, Enabled, DisabledThreading policy types

It also carries the internal helpers both downstream packages share: the element-type convention (_data_eltype / _filter_eltype), the threaded loop over independent FFTs (_foreach_chunk / _chunked_sum!), the scoped FFTW thread count (_with_fftw_threads), the boundary index folding (_clamp_idx) and the à trous pyramid filter construction (_nsp_atrous_filters) and its frequency responses (_nsp_responses), and the mask-bank engine that runs a nonsubsampled pyramid plus directional banks as products on the DFT grid (_MaskBankEngine).

Its only non-stdlib dependencies are Polyester (the task runner), NestedThreading (the FFTW thread budget) and FastBroadcast (the engine's same-size products).

MultiscaleFilterBanks.FilterPair — Type
FilterPair{T}

A 1-D biorthogonal filter pair holding an analysis (h) and synthesis (g) low-pass filter vector. Both filters are stored as coefficient vectors whose centre tap is at index ceil(Int, length/2) (1-based Julia indexing).

Examples

julia> using MultiscaleFilterBanks

julia> fp = FilterPair([0.5, 1.0, 0.5], [0.25, 0.5, 0.25]);

julia> eltype(fp)
Float64

MultiscaleFilterBanks.CDF97 — Constant
CDF97 :: FilterPair{Float64}

The standard CDF 9/7 biorthogonal filter pair. The 9-tap analysis filter and 7-tap synthesis filter are the JPEG2000 default low-pass filters.

julia> using MultiscaleFilterBanks

julia> isapprox(sum(CDF97.h), 1.0; atol = 1e-12)
true

julia> isapprox(sum(CDF97.g), 2.0; atol = 1e-12)
true

MultiscaleFilterBanks.upsample_filter — Function
upsample_filter(h::AbstractVector, factor::Int) -> Vector

Insert factor - 1 zeros between every tap of h. This implements the "à trous" (with holes) upsampling used by the nonsubsampled pyramid and the nonsubsampled directional filter banks to avoid downsampling at coarser levels.

Examples

julia> using MultiscaleFilterBanks

julia> upsample_filter([1.0, 2.0, 3.0], 2)
5-element Vector{Float64}:
 1.0
 0.0
 2.0
 0.0
 3.0

MultiscaleFilterBanks.ThreadingPolicy — Type
ThreadingPolicy

Abstract type for configuring the threading behavior of transforms. Available policies are:

  • Auto
  • Enabled
  • Disabled
source
MultiscaleFilterBanks.Auto — Type
Auto <: ThreadingPolicy

Automatically selects the optimal threading strategy based on the data type. By default, multithreading is disabled for Real data (which uses SIMD) and enabled for Complex data.

source
MultiscaleFilterBanks.Enabled — Type
Enabled <: ThreadingPolicy

Explicitly enables multithreading for loops.

MultiscaleFilterBanks.Disabled — Type
Disabled <: ThreadingPolicy
